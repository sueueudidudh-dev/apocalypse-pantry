# Еда для зомби-апокалипсиса: текстуры и эффекты

17 предметов, текстуры 16×16 в духе Farmer's Delight: обводка — тёмный оттенок своего цвета, свет сверху слева, без чистого чёрного и белого.
Файлы: `textures/<id>.png`, превью: `preview_sheet.png`, `preview_hotbar_x3.png`. Генератор: `make_textures.py` (Python + Pillow).

Как эффекты и блюда работают в моде на самом деле — см. README.md в корне проекта и `src/main/java/com/apocalypsepantry/Foods.java`.
